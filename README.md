# Silver Star Showcase

Create a premium, modern hotel website for “Hotel Silver Star”, Panipat.

IMPORTANT:

Use ONLY the attached/provided hotel images. Import them from the local assets folder and use them directly.

DO NOT use JSON image data, external image URLs, stock images, or placeholders.

STACK:

React + Vite + Tailwind CSS + Framer Motion.

DESIGN:

Elegant modern hotel UI with a clean luxury feel, cinematic hero, smooth scroll, subtle parallax, reveal animations, image hover effects, glass cards and excellent mobile responsiveness.

HOTEL:

Hotel Silver Star

Old Bus Stand Road, near Prem Hospital, Bishon Sarup Colony, Panipat, Haryana 132103

Phone/WhatsApp: +91 78766 77150

Rating: 4.8/5

Starting price: ₹818/night

PAGES:

Home | Rooms | Amenities | Gallery | About | Location | Contact

HOME:

Large image hero using attached hotel photos, hotel name, 4.8 rating, short tagline and strong “Book Now / WhatsApp / Call” CTAs.

ROOMS:

Create attractive room cards with pricing, comfort details and attached images.

AMENITIES:

Wi-Fi, clean rooms, room service, food, comfortable stay and other available facilities.

GALLERY:

Beautiful masonry/grid gallery using ONLY the imported attached images.

LOCATION:

Show the provided Google Maps embed.

Highlight Old Bus Stand, Panipat Junction, Prem Hospital and nearby city landmarks.

BOOKING:

Every Book Now, Enquiry, Room Booking and Contact action must open WhatsApp:

+91 78766 77150

Booking form should send Guest Name, Check-in, Check-out, Guests and Room/Requirement directly to WhatsApp.

Add floating WhatsApp + Call buttons on every page.

SEO:

Optimize for “Hotel Silver Star Panipat”, “hotel near Panipat bus stand”, “budget hotel in Panipat” and local searches.

Keep pages separate, components reusable, content-rich but uncluttered, fast and premium.
